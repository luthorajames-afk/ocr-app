# Rapport d'ajustement des seuils — T2.6 (analyse d'ablation)

Date : 2026-11-10 · Banc : `tests/bench/bench_runner.py --ablation` · Moteur : Tesseract 5.5.3 (200 DPI, corpus v2)

## Protocole

Trois configurations sur le même échantillon, CER/WER vs `truth.txt` :
1. **brut** — OCR direct, aucune transformation ;
2. **pretraite** — prétraitement automatique par triage (T2.2/T2.3) ;
3. **pretraite+lexique** — idem + post-correction lexique (T2.5).

## Résultats finaux (politique ajustée)

### Factures natives (6 documents — texte natif, R8)

| Configuration | CER | WER |
|---|---:|---:|
| brut | 6,71 % | 16,30 % |
| pretraite | 6,71 % | 16,30 % |
| pretraite+lexique | 6,71 % | 16,30 % |

Identique par construction : le chemin natif court-circuite l'OCR et le prétraitement.

### Scans (7 documents — OCR réel)

| Configuration | CER | WER |
|---|---:|---:|
| brut | 56,29 % | 69,50 % |
| **pretraite (ajusté)** | **49,91 %** | **65,42 %** |
| pretraite+lexique | 50,17 % | 66,34 % |

**Gain : −6,38 points de CER** vs brut. Le lexique est neutre à légèrement
négatif sur les scans bruités (+0,26 pt), à réserver aux textes propres.

## Itérations mesurées (traçabilité des seuils)

| Politique | CER scans | Verdict |
|---|---:|---|
| Binarisation auto si flou/faible contraste | 60,24 % (+3,95 vs brut) | Rejetée |
| Binarisation opt-in, deskew auto > 0,75° | 56,88 % (+0,59 vs brut) | Insuffisante |
| **Binarisation opt-in, deskew auto > 2°** | **49,91 % (−6,38 vs brut)** | **Retenue** |

Analyse par étape isolée (3 pages) : deskew seul 35,23 % vs brut 37,60 %
(−2,37 pts) ; Sauvola seul 42,04 % (+4,44 pts).

## Seuils retenus

| Paramètre | Valeur | Justification |
|---|---|---|
| `SKEW_TOLERANCE` (triage) | **2,0°** | Sous 2°, le redressement ajoute du flou d'interpolation sans gain mesurable |
| `binarize` (défaut) | **opt-in** | La binarisation automatique dégrade systématiquement le CER sur ce corpus |
| `binarize` (sauvola_window / k) | 25 / 0,2 | Non sensibles dans les plages testées ; à réévaluer par type de document |
| `deskew` | auto si inclinaison > 2° | Gain mesuré |
| Lexique | activable, non automatique | Neutre/négatif sur scans bruités ; à mesurer sur sorties Docling |

## Recommandations

1. **Ne pas activer Sauvola par défaut** ; le réserver aux documents très dégradés
   (< 20 de contraste RMS) ou après échec de la première passe (phase 3).
2. **Conserver le deskew automatique au-delà de 2°**.
3. **Lexique** : à réévaluer sur documents natifs et sorties du module Avancé.
4. **Seconde passe + vote bi-moteur** (T2.4) non inclus dans cette ablation :
   pas de second moteur dans le noyau ; à mesurer au branchement RapidOCR/Docling.
