## 2. Structure Qt cible (arbre des widgets)

```text
QMainWindow
├── QToolBar (AppToolbar)
│   ├── ModeSelector (QButtonGroup exclusif)  Simple | Moyen | Avancé | Approfondi
│   ├── QPushButton "Ajouter des fichiers"    (multi-sélection PDF/JPG/PNG)
│   ├── QPushButton "Scanner…"                (WIA/TWAIN/eSCL, désactivé si indisponible)
│   ├── QLabel info (langues · DPI · moteur · modules)
│   └── QPushButton "Réglages"
├── QSplitter horizontal
│   ├── TaskSidebar (QListWidget personnalisée)
│   │   └── TaskItem : nom, barre de progression (QProgressBar), statut coloré,
│   │                  étapes (render/preprocess/ocr/save), actions lot
│   └── QTabWidget résultats
│       ├── Onglet "Rendu"          → QTextBrowser (HTML propre)
│       ├── Onglet "Markdown/HTML"  → QPlainTextEdit lecture seule + sélecteur
│       └── Onglet "Texte brut"     → QPlainTextEdit éditable (R9)
├── PreviewPanel (au-dessus des onglets, splitter vertical)
│   ├── QGraphicsView  : image page réelle (page_NNN.png) + surcouches blocs
│   ├── Bandeau outils : Sélection | Zone d'exclusion | Supprimer | Original/Filtré
│   └── Bandeau zoom   : −  100 %  +
└── StatusBar (BottomBar)
    ├── QProgressBar + libellés (page, étape, %)
    ├── [Pause] [Annuler] [Copier ▾] [Exporter]
```

## 3. États et règles d'affichage

| Élément | Règle |
|---|---|
| Barre de progression par tâche | 0–100 %, étape courante en texte (épuré, sans animation) |
| Statut | En attente (gris), En cours (bleu), Terminé (vert), Annulé (gris), Erreur (rouge) |
| Surcouches de blocs | bleu accent, tag confiance ; zone d'exclusion = rouge tirets |
| Bouton Scanner | grisé avec tooltip si aucun backend (WIA/TWAIN/eSCL) |
| Mode Moyen/Avancé | grisé si module absent, tooltip « module non installé » |
| Édition | double-clic dans Rendu ou Texte brut ; Ctrl+Z/Y ; indicateur « ● modifié » |
| Fermeture | annulation propre des workers (aucun orphelin) |
